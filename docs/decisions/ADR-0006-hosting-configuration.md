# ADR-0006: Hosting configuration

- **Status:** Accepted
- **Date:** 2026-10-18
- **Deciders:** Project Owner
- **Related documents/ADRs:** AGENTS.md §1

## Context
Deciding on the hosting configuration is essential for ensuring performance and reliability of the application.

## Decision
The application will be hosted on Azure.

## Configuration Placeholders
- Azure settings: `Azure:Storage:ConnectionString`

## Alternatives considered
| Option | Pros | Cons | Why not chosen |
|---|---|---|---|
| On-premises hosting | Greater control | Higher maintenance costs | Cloud hosting provides better scalability. |

## Context
Deciding on the hosting configuration is essential for ensuring performance and reliability of the application.

## Decision
The application will be hosted on Azure.

## Configuration Placeholders
- Azure settings: `Azure:Storage:ConnectionString`

## Alternatives considered
| Option | Pros | Cons | Why not chosen |
|---|---|---|---|
| On-premises hosting | Greater control | Higher maintenance costs | Cloud hosting provides better scalability. |
| Other cloud providers | Potential cost savings | Complexity in migration | Azure offers better integration with existing systems. |

## Consequences
This decision will require the setup of Azure services and configurations for deployment.
